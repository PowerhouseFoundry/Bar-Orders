# Foundry Bar Drinks Receipt Training App

A standalone static till-training app for student receipt practice.

## What it does

- Combines the separate drinks receipt HTML files into one page.
- Uses a dropdown to switch between receipt modes:
  - Spirits only
  - Spirits & beers
  - Beers, mixers & spirits
  - Wines, beers, mixers & spirits
  - Full drinks menu
- Generates random receipt tickets with prices and totals.
- Lets students tap the large receipt when complete.
- Moves completed receipts into the history strip.
- Lets students tap a small receipt to view it again.

## GitHub Pages

1. Upload these files to a GitHub repository.
2. Go to **Settings > Pages**.
3. Choose the main branch and root folder.
4. Save.

## Render

Create a new **Static Site** on Render and connect your GitHub repository.

Suggested settings:

- Build command: leave blank
- Publish directory: `.`

The included `render.yaml` can also be used for Render Blueprint deployment.
